# Languages

The site runs in English (`/`), Yorùbá (`/yo`), Igbo (`/ig`), Hausa (`/ha`), French (`/fr`), German (`/de`), Spanish (`/es`) and Chinese (`/zh`).

| Layer | How it's translated |
|---|---|
| Interface text (navigation, headings, buttons, forms, footer) | Hand-written dictionaries in `src/worker/content/i18n.ts` |
| Product taglines and descriptions, case studies | Machine-translated on first view with Workers AI (`m2m100-1.2b`), then cached in KV for 30 days |
| Chat assistant | Replies in the visitor's language. It can also speak French, German, Spanish and Chinese with native voices, and Nigerian English for the rest. |
| Search engines | Each page lists all 8 versions with `hreflang` tags, and so does the sitemap |

## What needs a native speaker

The French, German, Spanish and Chinese dictionaries should read naturally, but a quick check by a native speaker is still worthwhile. **Yorùbá, Igbo and Hausa need review by a fluent speaker before you promote those versions.** Their tone marks and idioms matter, and machine translation is weakest in exactly these languages. Product pages in every non-English language show a small note that some text is machine-translated.

To fix a string: edit it in `i18n.ts`, commit, push. Workers Builds deploys it.
To fix a machine-translated product text: improve the English source, or tell us and we'll add a hand-written override.
